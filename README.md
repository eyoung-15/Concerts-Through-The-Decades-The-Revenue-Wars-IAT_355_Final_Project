**Concerts Through the Decades: The Revenue Wars - Interactive Data Visualization Web Application**

**Introduction to Visual Analytics (IAT 355) — Simon Fraser University**

Concerts Through the Decades: The Revenue Wars is an interactive scrollytelling data visualization exploring concert revenue trends from the 1980s through the 2020s.

Developed as a two-person team, the project uses D3.js visualizations and an interactive storytelling structure to compare concert performance across different decades and measurement criteria. The visualizations use multiple metrics to demonstrate how conclusions can change depending on whether concert performance is measured by raw revenue, inflation-adjusted revenue, or ticket sales. A minimalist interface was intentionally used to keep the focus on the data and reduce visual clutter.

**Features**

-Interactive decade-by-decade scrollytelling experience

-D3.js bar charts comparing: Actual concert revenue, Inflation-adjusted revenue, Tickets sold, Average ticket prices, All-time concert revenue

-Interactive tooltips for exploring individual data points

-Chart interactions and toggling

-User prediction/guessing interaction

-Responsive visualizations for different screen sizes

-Annotations and minimalist interface design

**Technologies**

JavaScript · D3.js · HTML · CSS
